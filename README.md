# AI-Intelligent-Companion
定制你的专属AI智能伴侣
1.需要安装相关包

  openai

  streamlit

2.运行代码

  streamlit run ai_parther.py

3.注意事项

  需要使用大模型API,并将大模型API key创建到环境变量中

  变量名DEEPSEEK_API_KEY,变量值 API key

  本代码使用openai框架

  可兼容openai和deepseek

  若使用其他模型,请视情况修改

  本代码使用虚拟环境创建

  python=3.8

  streamlit并非最新版本

  若使用最新版本,请将代码中use_container_width修改为width
